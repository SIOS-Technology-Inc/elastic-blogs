# ハイブリッド検索のテスト

## ハイブリッド検索

下記を行うクエリーを ES|QL を使って記述する。

- キーワード検索を行い、結果の上位10件を取得する。

- セマンティック検索を行い、結果の上位10件を取得する。

- それぞれの検索結果の順位を元に RRF でリランクし、上位10件を返す。

```
POST /_query
{
  "query": """
FROM kakinosuke_202609 METADATA _score, _id, _index
| FORK (WHERE MATCH(content.semantic, ?query) | SORT _score DESC | LIMIT 10)
       (WHERE MATCH(content, ?query) | SORT _score DESC | LIMIT 10)
| DROP content.semantic
| FUSE
| KEEP chunk_no, content, _score
| SORT _score DESC
| LIMIT 10
""",
  "params": [
    { "query": "柿之助の3人の家来は?" }
  ]
}
```

FORK でセマンティック検索とキーワード検索を行います。

FUSE で2つの検索結果を融合(RRF)します。
