# セマンティックリランクのテスト

## 事前準備

Elasticsearch から Elastic Cloud の EIS 機能を経由して .jina-reranker-v3.5 を利用できるよう設定しておく。

## セマンティックリランク

下記を行うクエリーを ES|QL を使って記述する。

- キーワード検索を行い、結果の上位10件を取得する。

- セマンティック検索を行い、結果の上位10件を取得する。

- それぞれの検索結果の順位を元に RRF でリランクし、上位10件を返す。

- その10件をセマンティックリランカーに渡し、リランクしてもらう。
  - セマンティックリランカーには、 .jina-reranker-v3.5 を利用する。

- 最終的な上位5件を返す。

```
POST /_query
{
  "query": """
FROM kakinosuke_202609 METADATA _score, _id, _index
| FORK (WHERE MATCH(content.semantic, ?query) | SORT _score DESC | LIMIT 10)
       (WHERE MATCH(content, ?query) | SORT _score DESC | LIMIT 10)
| FUSE RRF
| KEEP chunk_no, content, _score
| SORT _score DESC
| LIMIT 10
| RERANK ?query ON content WITH { "inference_id" : ".jina-reranker-v3.5" }
| SORT _score DESC
| LIMIT 5
""",
  "params": [
    { "query": "柿之助の3人の家来は?" }
  ]
}
```

ハイブリッド検索結果を元に RERANK で、セマンティックリランカーを呼び出します。
