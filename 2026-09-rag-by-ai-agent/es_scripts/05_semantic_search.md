# セマンティック検索のテスト

## 準備

Elasticsearch から Elastic Cloud の EIS 機能を経由して .jina-embeddings-v5-text-nano を利用できるよう設定しておく。

## セマンティック検索

下記を行うクエリーを ES|QL を使って記述する。

- セマンティック検索を行い、結果の上位10件を返す。
  - クエリーからのベクトル生成には、.jina-embeddings-v5-text-nano が利用される。

```
POST /_query
{
  "query": """
FROM kakinosuke_202609 METADATA _score, _id, _index
| WHERE MATCH(content.semantic, ?query)
| KEEP chunk_no, content, _score
| SORT _score DESC
| LIMIT 10
""",
  "params": [
    { "query": "柿之助の3人の家来は?" }
  ]
}
```

※KNNを使わなくても MATCH と書いてセマンティック検索が行われます。
