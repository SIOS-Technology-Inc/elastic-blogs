# キーワード検索のテスト

## キーワード検索

下記を行うクエリーを ES|QL を使って記述する。

- キーワード検索を行い、結果の上位10件を返す。

```
POST /_query
{
  "query": """
FROM kakinosuke_202609 METADATA _score, _id, _index
| WHERE MATCH(content, ?query)
| KEEP chunk_no, content, _score
| SORT _score DESC
| LIMIT 10
""",
  "params": [
    { "query": "柿之助の3人の家来は?" }
  ]
}
```
