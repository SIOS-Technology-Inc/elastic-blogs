# ベクトル検索のテスト

下記を行うクエリーを ES|QL を使って記述する。

- ベクトル検索を行い、結果の上位20件を返す。
  - ベクトル検索には、.jina-embeddings-v5-text-nano を利用する。

```
POST /_query
{
  "query": """
FROM waganeko METADATA _score, _id, _index
| WHERE KNN(content_embedding, TEXT_EMBEDDING(?query, ".jina-embeddings-v5-text-nano"))
| KEEP chunk_no, content, _score
| SORT _score DESC
| LIMIT 20
""",
  "params": [
    { "query": "吾輩が生まれた場所は?" }
  ]
}
```
