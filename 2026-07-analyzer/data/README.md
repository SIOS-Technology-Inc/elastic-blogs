# テストテキストについて

本比較で使う2つの日本語テキストです。
どちらも医療系の文章です。

| ファイル | 内容 | 文字数の目安 | ねらい |
|---|---|---|---|
| `text1_loxonin.txt` | ロキソニンの説明文（前回の記事と同じ文） | 約137文字 | なじみのある短い例。 |
| `text2_medical.txt` | アセトアミノフェンの説明文（本記事用に書き下ろし） | 約290文字 | 専門用語を多く含む、少し長い例。 |

注意：本記事は前年と同一条件の定点観測ではありません。
Text 1 は「同じ文」を使いますが、数値を前回とそのまま引き算しないでください。
理由は `METHODOLOGY.md` を参照してください。

## text2 に含めた「難しい要素」

アナライザーの差が出やすいポイントを、意図的に入れています。

- カタカナ語・薬品名：`アセトアミノフェン` / `アナフィラキシーショック` /
  `スティーブンス・ジョンソン症候群` / `インフルエンザ`
- 英語の略語：`NSAIDs`
- 漢字の複合語：`中枢神経系` / `解熱鎮痛薬` / `非ステロイド性抗炎症薬` / `肝機能障害`
- 数値・用量の表現：`1回300〜500mg` / `1日3回`

## 注意

`text2_medical.txt` は、トークン化の挙動を確認するためのサンプル文です。
医療上の助言ではありません。
内容の正確さよりも、比較に向いた語彙を含むことを優先しています。
