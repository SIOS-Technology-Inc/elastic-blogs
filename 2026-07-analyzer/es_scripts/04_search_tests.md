# 04. 検索クエリでの動作確認

トークンが似ているかどうかだけでなく、
「実際の検索で、目的の文書が拾えるか」を確認します。
ここが、検索システムとして一番大事なところです。

## 1. テスト用の文書を登録する

`jp_kuromoji` インデックスに、少数の文書を登録します。
`content` は標準 `kuromoji`、`content_search` は `mode: search` のアナライザーが効きます。

```json
POST /jp_kuromoji/_bulk
{ "index": { "_id": "1" } }
{ "content": "関西国際空港は大阪府にある国際空港です。", "content_search": "関西国際空港は大阪府にある国際空港です。" }
{ "index": { "_id": "2" } }
{ "content": "アセトアミノフェンは解熱鎮痛薬で、非ステロイド性抗炎症薬（NSAIDs）とは異なります。通常は1回300〜500mgを服用します。", "content_search": "アセトアミノフェンは解熱鎮痛薬で、非ステロイド性抗炎症薬（NSAIDs）とは異なります。通常は1回300〜500mgを服用します。" }
{ "index": { "_id": "3" } }
{ "content": "ロキソニンは解熱鎮痛作用のある薬で、痛みや発熱を抑えます。", "content_search": "ロキソニンは解熱鎮痛作用のある薬で、痛みや発熱を抑えます。" }
```

## 2. クエリと「期待するヒット」を決めて確認する

あらかじめ正解を決めておき、実際にヒットするかを見ます。

| クエリ | 期待するヒット | 見たいこと |
|---|---|---|
| `空港` | doc 1 | 複合語 `関西国際空港` の中の「空港」で拾えるか |
| `関西空港` | doc 1 | 一般的な略称で拾えるか |
| `NSAIDs` | doc 2 | 英字の専門語が保持され検索できるか |
| `300mg` | doc 2 | 数値＋単位で検索できるか |
| `アセトアミノフェン` | doc 2 | 医療系の専門語が1語として拾えるか |

標準アナライザーの `content` で検索：

```json
GET /jp_kuromoji/_search
{
  "query": { "match": { "content": "空港" } }
}
```

`mode: search` の `content_search` で検索：

```json
GET /jp_kuromoji/_search
{
  "query": { "match": { "content_search": "空港" } }
}
```

`空港` / `関西空港` / `NSAIDs` / `300mg` / `アセトアミノフェン` を順に試します。

## 3. Sudachi でも同じ確認をする

`jp_sudachi` に同じ文書を登録し、`content_a` / `content_b` / `content_c` に対して
同じクエリを実行します。
モードによって複合語の扱いが変わるため、ヒットのしやすさが変わります。

## 見るポイント

- 標準 `kuromoji` と `mode: search` で、`空港` のヒットに差が出るか。
- Sudachi の A（細かい）と C（大きい単位）で、`関西空港` のヒットに差が出るか。
- `NSAIDs`、`300mg` のように、英字・数値・単位がそのまま検索できるか。
